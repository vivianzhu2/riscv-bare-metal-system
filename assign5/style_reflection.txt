A single clear box test for recycling would be to malloc a block, save its address, free it, then malloc the same size again and assert the returned address matches the saved one. 
This confirms that malloc is reusing the freed block rather than always extending the heap with sbrk.  However this test is very narrow and only confirms recycling works for the exact same size request in isolation with no other allocations in between. 
To get confident coverage you would need additional tests: freeing a large block then mallocing something smaller into it, freeing two adjacent blocks and mallocing something that only fits in the combined space, and interleaving many mallocs and frees to ensure recycling still works when the heap is split. 
Each one would need to elaborate on a specific memory address. It does not confirm that a smaller request can fit into a larger freed block, that the leftover memory after a smaller allocation is still usable.
