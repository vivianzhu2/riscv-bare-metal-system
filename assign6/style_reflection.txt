2. Read one or both of the short readings below introducing design patterns. Pick a pattern from the reading that you find interesting and explain it to us. Give us an example of how you would use this pattern and why it would be useful. Include a pseudocode example.

In the flyweight design pattern, it relies on two objects: the main object with most of the backbone and structure of each of the objects, and then the individual objects that are variations of the main object with characteristics like color or size or type. This 
class OutfitModel
{
private:
  Clothing shirt;
  Clothing pants;
  Clothing shoes;
};
This clothes example represents the flyweight design pattern because the fundamental outfit structure doesnt change, but the design of the clothes can. Like the individual shirt, pants, and shoes are customizable in the individual trees, but
in the overall structure, the general ones are defined by a main pattern. Every outfit has these components, and this encapsulates all of the outfits, so it only needs to be declared once. 

class Outfit
{
private:
  Texture* cotton;
  String weather;
  Category Occasion;
  int Casual;
}; 

This instantiates each individual outfit, by ranking how dressy it is, when it is suitable to wear, if it is according to the temperature, and also the material of the clothing articles. 
This is unique to each outfit and can be personalized by the user by referring to the model but customizing to these attributes.
